## Foundry v12 integration

Uses legacy Application/Dialog/Handlebars supported in v12, Document UUID APIs, standard TextEditor drag data, world Compendium persistence. API references: [Application](https://foundryvtt.com/api/v12/classes/client.Application.html), [CompendiumCollection](https://foundryvtt.com/api/v12/classes/client.CompendiumCollection.html). No v13-only APIs.

The private world JournalEntry compendium `world.cpr-net-architect` stores templates and the active session separately; it is created with GM/assistant ownership and no player/trusted ownership. Names in its index are opaque. Do not change this pack's permissions. Module socket traffic is encrypted and authenticated per user with WebCrypto ECDH + AES-GCM, using public keys published on server-permissioned User flags. The lowest-ID connected GM is authoritative. Full state is never broadcast in plaintext. Completion requests carry a chat-message ID, never a result total. The authority verifies the author and one-use grant and reads the native result recorded in that message; this uses the same client-side dice trust as ordinary Foundry rolls. Replays and stale session revisions are rejected. HTTPS (or localhost) is required for default WebCrypto mode. The GM may explicitly enable the world HTTP compatibility setting; every client must reload to use the bundled NaCl transport.

## Verification boundary

Strict DV comparison is also confirmed by the publisher's [Edgerunner Folio](https://rtalsoriangames.com/wp-content/uploads/2024/07/RTG-CPR-DLC-Edgerunner-Folio.pdf): a check must exceed its DV. No proprietary generation tables or long rulebook passages are embedded in this module.

Source inspection is complete. Automated adapter-contract and engine tests run outside Foundry. Actual startup and the multiplayer acceptance scenario on hosted Foundry **12.343** remain manual acceptance checks; source inspection alone cannot establish runtime certification.

Item pickup uses CPR Actor `createEmbeddedDocuments("Item", data, {createInstalled:false, CPRsplitStack:true})`, preserving a distinct claim marker without native auto-stacking or copying installed child references. Journal text uses native `TextEditor.enrichHTML` with player secrets disabled and Observer checks on each page.

### HTTP compatibility transport (0.3.0)

All opted-in clients use a distinct `nacl-box-v1` public-key format on the existing server-permissioned User flag. Secret keys remain in client memory. Peer Curve25519 keys must have a nonzero shared secret. Each box uses a fresh 24-byte nonce from `crypto.getRandomValues`; the routing header is included inside the authenticated ciphertext and checked against the envelope. The existing time window, replay cache, sender checks, recipient checks and GM authority validation still apply. Mode mismatch fails closed; there is no automatic downgrade or plaintext path. Changed public keys invalidate the peer-key cache.

The bundled dependency is pinned and its npm SHA-512 integrity was verified. Only an ES-module wrapper was added; see `scripts/vendor/README.md` and the included Unlicense. This module protocol has regression tests but has not received an independent security audit. Application encryption cannot establish secure transport when HTTP code/key delivery is actively intercepted.
